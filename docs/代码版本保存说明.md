# 代码版本保存说明

2026 年 10 月 15 日建立本地 Git 仓库，保存后续方案讨论前的代码基线。本次没有修改业务逻辑，也没有重新生成动作。

当前基线包含机器人混合动作、IK 与动作时间轴工具、相机可见性检查、自动补光、网页和测试。相机案例已修正，但原搬椅动作没有有效执行双手接触；最近的旧双人视频来自误回退期间，不能代表恢复后的流程。接触能力如何接入和验收，留待下一步方案确认后修改。

代码、测试、知识目录、Skill、启动脚本和 Markdown 文档纳入 Git。素材、视频、生成报告、Blender 与 FFmpeg 运行环境、私有配置及历史敏感交接文件保留在磁盘上，不纳入本次代码提交。这是代码检查点，不是完整离线运行环境备份。

`hermes/` 是独立的外部仓库。其当前来源和提交记录在 `config/hermes-source.json`，现有依赖锁文件另存为 `config/hermes-uv.lock`，外层仓库不改动该依赖仓库。

查看提交及后续改动：

```bash
git log --oneline -5
git status --short
git diff
```

开始新方案时可以创建分支；需要取回旧文件时，从检查点恢复指定文件，避免把整个工作区和未提交成果一起覆盖。
